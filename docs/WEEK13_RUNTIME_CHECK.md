## 원인 (코드 확인)
- 복귀 실패: `onPause`가 화면 상태를 `frozenUi`에 저장하지만 같은 인스턴스의 `onResume`에서 그것을 복원 대기(`pendingUi`)로 넘기는 경로가 없음 → `RestorationGate.READY`에서 복원할 것이 없음.
- 프로세스 종료 후: `onSaveInstanceState`에 recap/offset/scroll이 들어가는데도 첫 화면 — 추가 조사 필요.
- 메인 CPU: 메인 프로세스가 잠금 판단용으로 차량 속도를 약 10Hz로 구독하고 콜백마다 `car.property.callback` 로그를 남김(주행 중엔 화면이 잠겨 있어 불필요).
- 복기 열기 지연: 카드 100장을 한 번에 뷰로 생성(리사이클 없음) → UI 스레드 약 2초 점유.

- release에서는 모의 내비가 꺼져 있다(`BuildConfig.DEBUG` 조건). 그래서 회전·유턴 카드는 내비 없는 기본 판정(일반 회전 숨김)을 따르고, 시나리오 주입도 내비를 빼고 했다(`.local/release_check/feed_nonavi.ps1`).
- release 로그에는 카드 상세가 남지 않는다(`event=drive.recap.card`만). 판정은 복기 화면 UI 덤프로 읽었다.
- **주의(중계 서버):** 처음에는 AI 한마디가 기본 문구로 나왔다.
  - 직접 확인해 보니 외부 AI(OpenCode Go)는 정상이었다(2.3초, 200).
  - 중계 서버를 재시작하자 바로 AI 문장이 나왔다.
  - 오래 켜 둔 서버가 업스트림 401을 한 번 받고 키를 비운 상태였을 가능성이 높다. 401 뒤에는 재시작 전까지 멈추도록 설계돼 있다.
  - 시연 직전에는 중계 서버를 재시작할 것. 일정 시간 뒤 다시 시도하도록 바꿀지는 검토 후보다.
