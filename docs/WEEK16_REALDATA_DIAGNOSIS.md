# W16 사전 진단 — 실제 현대·기아 주행 데이터에서 차선 변경 판정 (2026-10-24)

## 데이터
- commaCarSegments(Hugging Face `commaai/commaCarSegments`, MIT), 현대·기아 8차종 91구간(각 1분, 주행 중 잘라낸 조각), 시속 25km 이상 주행 74분.
- 엔진 입력으로는 CAN에서 핸들각(SAS11), 바퀴 속도(WHL_SPD11), 깜빡이 램프(CGW1), 브레이크(TCS13)만 썼다.
- 정답은 엔진이 쓰지 않는 요레이트(ESP12)와 바퀴 속도·깜빡이로 만들었다(`ccs/ccs_truth_v2.py`).
  - 3~8초 사이 진행 방향이 나갔다 돌아오고, 옆으로 2.5~5m 이동한 움직임을 차선 변경으로 본다.
  - 다음 경우는 '애매'로 빼고 채점하지 않는다.
    - 교차로 회전 맥락: 앞뒤 5초 방향 출렁임 20° 초과
    - 25km/h 미만
    - 12초 초과
    - 구간 경계 2초 이내

## 정답의 한계(먼저 읽을 것)
- 정답과 슬라이딩 창 탐지는 같은 기하 정의를 쓴다. 그래서 창 방식의 재현율은 구조상 높게 나오고, 엔진과 같은 조건에서 비교하는 용도로만 쓴다.
- CAN만으로는 차선 변경과 도로 S자·차로 이동 구간을 구별할 수 없다. 카메라 정답이 필요하다(comma2k19 토렌트는 시더 0으로 받지 못함).
- 정답 v1에서 '깜빡이 확인 차선 변경 30건'으로 봤던 사례는 대부분 교차로 회전 끝부분이었다. 예: 소나타 핸들 -215°→0°, 깜빡이는 회전용.
  - v2에서는 깜빡이 동반 깨끗한 차선 변경이 4건뿐이라 정확도 주장에 쓸 수 없다.

## 결과 (정답 v2, 깨끗한 차선 변경 모양 56건)

| 방식 | 현대 35건(값 고르기) | 기아 21건(검증) | 깜빡이 확인 4건 | 정답 밖 탐지 |
|---|---|---|---|---|
| 엔진 1.5.2 | 2 | 0 | 1 | 0 |
| 스파이크A: 주행 중에도 느린 영점 학습(τ30s) | 4 | 0 | 1 | 0 |
| 핸들 슬라이딩 창(조향비 15, 옆 2~6m, 고역 6s, 시작 4초 제외) | 29 | 16 | 4 | 시간당 10~13 |

- 정답 밖 탐지(워밍업 전 24건)를 요레이트로 다시 재면 세 갈래로 나뉜다(`ccs/ccs_check_extra.py`).
  - 구간 시작 계산 잔상: 약 6건. 워밍업으로 제거된다.
  - 곡선 도로 위: 12건. 실제 차선 변경인지 곡선 진입·이탈 잔상인지 구별할 수 없다. 정답이 곡선 위 차선 변경을 못 보기 때문이다.
  - 실제 옆 이동 1.5m 미만: 고속 잡음과 조향비 차이 때문이다.
- 곡선 전이 거르기(창 안 도로 성분 변화량 문턱)는 재현율만 떨어뜨리고 정답 밖 탐지는 줄이지 못했다.

## 원인: 핸들 영점 고착(자기 잠금)
추적: `ccs/*.tsv`, `RealDataTraceTest`.
1. 시작 3초 보정(τ1s)이 그 순간의 곡선 핸들각이나 센서 오프셋을 영점으로 잡는다.
   - 셀토스: 영점 -3.91°, 실제 직진 약 0°.
   - 팰리세이드: +2.20°, 실제 약 -1°.
   - 엘란트라: -0.70°, 실제 +0.7° 안팎.
2. 시속 100km에서 영점 1°가 틀리면 추정 횡가속도 약 0.4m/s²가 생긴다. 중립 문턱은 0.2m/s²다.
   - 그래서 구간이 닫히지 않고, 10초 상한(MAX_CANDIDATE_MS)에 걸려 INCOMPLETE → '확인 필요'나 CURVE로 끝난다.
   - 옆 이동 적분은 50~85m까지 커진다.
3. 영점은 열린 구간이 없을 때만 배운다. 그런데 틀린 영점 때문에 구간이 거의 항상 열려 있어서 영점이 다시 바로잡히지 않는다.
4. 시뮬레이터는 영점이 맞고 노면 기울기가 ±0.5°라서 이 실패를 드러내지 못했다. 시뮬 기준 98~99% 같은 수치는 실주행에서 성립하지 않는다.

## 시사점
- 영점만 고치는 방법(스파이크A)으로는 부족하다. 구간을 열어 두고 중립을 기다리는 구조 자체가 실제 핸들 잡음에 약하다.
- 복기는 주차 뒤에 보여 주므로 판정을 약 10초 늦춰도 된다. 도로 성분을 앞뒤 3초 이동평균으로 빼고 3~8초 창에서 모양을 보는 방식이 실데이터에서 훨씬 낫다.
  - 메모리는 고정 크기 링버퍼 약 15초면 된다.
- 다만 정답 밖 탐지(시간당 10건 안팎)를 검증할 방법이 없다. 그래서 '깜빡이 없이 차선 변경' 카드는 보수적으로 내야 한다. 틀린 경고는 신뢰를 깎기 때문이다.
