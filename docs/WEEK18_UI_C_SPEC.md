# 1.8.0 설계: 복기 화면 C안 "한 장씩" (2026-10-25)

## 결정
- 사용자가 시안 C(`docs/design/ui_v2/C_frame.png`, 생성기 `make_concepts.py`의 `concept_c`)를 골랐다. 톤은 "운동 앱처럼 담백하게".
- 바꾸는 곳은 **정차 후 복기 화면**(`MainActivity.renderRecap`)과 그 카드(`reviewTile`)만. 홈 화면, 기록 흐름, 엔진 판정, 저장 형식은 바꾸지 않는다.

## 화면 구성 (넓은 화면, connect-s 1682dp 기준)
1. 머리: "오운복" + 날짜 · 주행 시간 · (거리를 알 수 있으면 거리). 그 아래 순간 개수만큼 **진행 막대 칸**(지금 보는 칸만 진하게).
2. 왼쪽 큰 카드(순간 하나):
   - 윗줄 색 글자: `종류 · n / N · 시:분` (잘한 순간=파랑 #0064FF, 놓친 순간=#E5482C, 늦게 켬=#E89A00, 켜 둔 채=#8A5CF6, 급제동=#131417, 애매함·기타=회색).
   - 큰 제목(2줄까지): 사람 말 문장. 예) "깜빡이를 켜고 45m 뒤에 차선을 바꿨어요", "깜빡이 없이 차선을 바꿨어요", "핸들이 먼저 돌고 깜빡이가 0.5초 늦었어요", "깜빡이를 켠 채 23초를 달렸어요", "60km/h에서 12km/h로 급하게 섰어요". 회전도 같은 방식. "위반" 같은 법적 판단 말은 금지, 기준은 "권장 거리".
   - 그림 한 줄(종류별):
     - 먼저 켬 + 켬 거리 있음: 시안의 **켬 거리 막대**(깜빡이 켬 ○ → 차선 진입 ● · Nm, 권장 30m(고속 기준이면 100m) 점선 눈금).
     - 켜 둔 채 주행: 같은 막대 모양으로 켠 시간(초) 막대 + 15초 눈금.
     - 나머지: 큰 숫자 칩 2~3개(속도, 핸들 지속 시간, 깜빡이 늦은 시간/감속).
   - 근거 칩: 사람 말로. "핸들 원시 7.0→-6.0" 같은 원시값은 **Debug 화면에서만** 보이고 기본 화면에서는 "핸들 5.1초"처럼. "추정"·"내비 확인" 같은 판정 출처 표시는 칩 하나로 남긴다(신뢰 표시라 지우지 않는다).
   - "오늘 주행 중 위치": 그날 첫 순간~마지막 순간(또는 기록 시작~끝)을 가로축으로, 순간마다 종류 색 점, 지금 순간은 크게. **속도 곡선은 그리지 않는다**(속도 기록을 저장하지 않으므로. 새 저장 금지).
   - 아래 버튼: ‹ 이전 · 맞아요 · 아니에요 · 다음 ›. 맞아요/아니에요는 지금 동작(피드백 저장) 그대로. 점을 눌러도 그 순간으로 이동.
3. 오른쪽 좁은 열:
   - "오늘 한눈에": 종류별 개수(잘한 순간·놓친 순간·늦게 켬·켜 둔 채·급제동, 0인 줄은 숨김). **지금 "깜빡이 놓침" 타일이 켜 둔 채 주행까지 합산하는 문제를 여기서 바로잡는다** — 종류별로 따로 센다.
   - "오늘의 한마디 · AI": 지금 AI 요약 그대로(대기·실패·다시 확인 상태 포함).

## 좁은 화면·다른 폼팩터
- 기존 반응형 규칙(`wide` 분기, 폼팩터 테스트 `test-responsive.mjs`·`capture-responsive.ps1`)을 지킨다. 좁으면 오른쪽 열을 카드 아래로 내린다. 글자 최소 크기·터치 영역은 기존 Pleos 토큰 기준.
- 다크 모드(야간)는 기존 색 토큰 매핑을 따른다.

## 바꾸지 않는 것
- 판정 엔진·임계값, 저장 스키마, AI 계약, 홈 화면, 주행 중 잠금, 릴리스 서명.

## 검증
- `:logic:test`·`:app:assembleDebug` 통과. 문구 함수(제목·칩)는 logic 쪽 순수 함수로 두고 단위 테스트(종류별 제목, 원시값 미노출, "위반" 금지, 놓침/켜 둔 채 분리 집계).
- 에뮬레이터: 시나리오 H(`scripts/recap-scenario-h.json`, 내비 없이 `.local/release_check/feed_nonavi.ps1`)로 카드 5장 만든 뒤 복기 화면 캡처(첫 장, 켜 둔 채 장, 다음/이전 이동, 점 눌러 이동, 맞아요 저장 후 다시 열기). 좁은 폼팩터 캡처 1장.
